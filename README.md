# AWS Static Website — S3 + CloudFront

A static website hosted on AWS S3 with CloudFront CDN.

## What I built
- HTML/CSS site uploaded to S3
- CloudFront CDN for HTTPS and global delivery
- S3 versioning enabled for rollbacks
- Access logging to a separate S3 bucket

## Services used
- Amazon S3
